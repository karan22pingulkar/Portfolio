# Portfolio

Personal portfolio website — dark sci-fi/terminal theme, pure HTML + CSS + vanilla JS, no build step.

**Live:** [karan-pingulkar.is-a.dev](https://karan-pingulkar.is-a.dev)

## Stack

- Static site on GitHub Pages, custom domain via [is-a.dev](https://is-a.dev)
- Canvas starfield, custom cursor, coverflow experience carousel, typewriter bio

## Workflow

- `dev` branch = work, `main` branch = live site
- Edit → commit on `dev` → merge into `main` → push → auto-deploys in ~30s

## Updating

- **Resume:** overwrite `assets/resume/resume.pdf` (keep the filename)
- **Text/links:** everything is in `index.html`
- **Colors:** palette variables at the top of `css/style.css`
