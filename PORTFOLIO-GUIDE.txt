THE ONLY COMMAND YOU NEED TO KNOW — "SHIP IT"
============================================================
After editing any file (and saving with Ctrl+S), run this in
PowerShell / terminal inside D:\Portfolio:

  git add -A
  git commit -m "describe what you changed"
  git push origin dev
  git switch main
  git merge dev
  git push
  git switch dev

That's it. The site updates live in ~30 seconds.

BRANCHES EXPLAINED
  dev  = where you work (safe, nothing goes live)
  main = what the public sees (GitHub Pages builds from this)

============================================================
IF SOMETHING LOOKS BROKEN
============================================================

"MY CHANGES AREN'T SHOWING"
  Your browser cached the old files. Press  Ctrl+Shift+R
  (hard refresh). Or open the site in an incognito window.
  This fixes it 90% of the time.

"GIT STATUS SHOWS A CONFLICT / FILE IS NEWER ERROR IN EDITOR"
  It means the file on disk is newer than what's in the editor.
  Close the file tab WITHOUT saving, reopen it. Done.

"COMMIT DIDN'T COUNT ON MY GITHUB GRAPH"
  Commits only count once they're merged to main AND pushed.
  Also check: github.com/settings/emails — your git email
  (karan22pingulkar@gmail.com) must be listed there.

"THE DOMAIN STOPPED WORKING"
  - Check github.com/karan22pingulkar/Portfolio -> Settings -> Pages
    is still "main / root" and custom domain is filled in.
  - is-a.dev records live in your fork: github.com/karan22pingulkar/register
    (domains/karan-pingulkar.json must say CNAME karan22pingulkar.github.io)

"I MESSED SOMETHING UP"
  Nothing is ever lost — git has every version.
  See history:     git log --oneline
  Undo last commit (keep the changes):  git reset --soft HEAD~1
  Restore a file to last commit:        git checkout -- filename
